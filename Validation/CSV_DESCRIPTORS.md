# CSV descriptors for `Validation/`

This file documents the CSV outputs generated by the validation scripts.

## Equilibrium spacing validation CSVs

Applies to:

- `idm_equilibrium_spacing_validation.csv`
- `fvdm_equilibrium_spacing_validation.csv`

Rows are tested equilibrium velocity values.

| Column | Unit | Description |
|---|---:|---|
| `velocity_mps` | m/s | Velocity used as the test input. |
| `manual_spacing_m` | m | Equilibrium spacing calculated directly from the model formula. |
| `code_spacing_m` | m | Equilibrium spacing returned by the model implementation. |
| `spacing_difference_m` | m | `code_spacing_m - manual_spacing_m`. |
| `recovered_velocity_mps` | m/s | Velocity recovered from the inverse relation. |
| `velocity_difference_mps` | m/s | `recovered_velocity_mps - velocity_mps`. |

Expected values: spacing and velocity differences should be near numerical
round-off.

## Solver comparison CSVs

Applies to:

- `idm_solver_comparison*.csv`
- `fvdm_solver_comparison*.csv`

Rows are simulation time steps. These files compare Euler and RK4 speed
profiles for the same model.

| Column | Unit | Description |
|---|---:|---|
| `time_s` | s | Simulation time stamp. |
| `total_abs_velocity_difference_mps` | m/s | Sum of absolute speed differences. |
| `mean_abs_velocity_difference_mps` | m/s | Mean absolute velocity difference across vehicles. |
| `max_abs_velocity_difference_mps` | m/s | Maximum absolute velocity difference across vehicles. |

Expected values: residuals should decrease as the supplied time step `dt`
decreases.

## Factor-collapse summary CSVs

Applies to:

- `midm_factor_validation_dt_0p1.csv`
- `mfvdm_factor_validation_dt_0p1.csv`

Rows are simulation time steps. These files summarize how closely the
multi-anticipation model collapses to the base model when only the immediate
leader is weighted.

| Column | Unit | Description |
|---|---:|---|
| `time_s` | s | Simulation time stamp. |
| `max_abs_velocity_residual_mps` | m/s | Maximum absolute speed difference. |
| `mean_abs_velocity_residual_mps` | m/s | Mean absolute speed difference over compared vehicles. |
| `max_abs_position_residual_m` | m | Maximum absolute position difference over compared vehicles. |
| `mean_abs_position_residual_m` | m | Mean absolute position difference over compared vehicles. |

## MIDM factor-collapse vehicle residuals

Applies to:

- `midm_factor_validation_vehicle_residuals_dt_0p1.csv`

Rows are vehicle-time observations.

| Column | Unit | Description |
|---|---:|---|
| `time_s` | s | Simulation time stamp. |
| `vehicle` | - | Compared vehicle index. |

| `velocity_residual_mps` | m/s | `midm_velocity_mps - idm_velocity_mps`. |

## Identical-profile comparison CSVs

Applies to:

- `midm_idm_identical_dt_0p1.csv`
- `mfvdm_fvdm_identical_dt_0p1.csv`

Rows are simulation time steps. These files compare the base-model follower
against the equivalent multi-anticipation follower when the first three upstream
speed profiles are made identical.

`midm_idm_identical_dt_0p1.csv` columns:

| Column | Unit | Description |
|---|---:|---|
| `time_s` | s | Simulation time stamp. |
| `idm_vehicle_2_position_m` | m | IDM comparison vehicle position. |
| `midm_vehicle_4_position_m` | m | MIDM comparison vehicle position. |
| `position_residual_m` | m | MIDM position minus IDM position. |
| `idm_vehicle_2_velocity_mps` | m/s | IDM comparison vehicle speed. |
| `midm_vehicle_4_velocity_mps` | m/s | MIDM comparison vehicle speed. |
| `velocity_residual_mps` | m/s | MIDM speed minus IDM speed. |

`mfvdm_fvdm_identical_dt_0p1.csv` uses the same layout, with FVDM and MFVDM
column names replacing IDM and MIDM.

## Two-step validation CSVs

Applies to:

- `midm_two_step_validation_dt_0p1.csv`
- `mfvdm_two_step_validation_dt_0p1.csv`

Rows are simulation time steps. These files compare a downstream vehicle from a
full first run against the mapped vehicle in a second run with hard-coded
upstream boundary profiles.

| Column | Unit | Description |
|---|---:|---|
| `time_s` | s | Simulation time stamp. |
| `first_run_physical_100_velocity_mps` | m/s | Speed of physical vehicle 100 in the first run. |
| `second_run_row_50_velocity_mps` | m/s | Speed of row 50 in the second run. |
| `velocity_residual_mps` | m/s | Second-run speed minus first-run speed. |

The scripts also print the normalized L2 residual:

```text
||velocity_residual|| / ||first_run_physical_100_velocity||
```

This is the main scale-independent error indicator for the two-step checks.

## `idm_validation_sun_dt_<dt>.csv`

Rows are simulation time steps. This file compares a local Euler update against
the Euler method reached through the solver flow.

The file contains time, compared speed/position profiles, and residual columns.
Columns ending in `_mps` are speeds in `m/s`, columns ending in `_m` are
positions in `m`, and residual columns are differences between the two Euler
implementations.
